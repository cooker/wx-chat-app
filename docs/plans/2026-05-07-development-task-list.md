# 仿小红书相册APP 开发任务清单

## 目标
基于 `Spring Boot 3 + Vue 3 + SQLite + MyBatis` 搭建一个包含后台管理端与用户侧前端的相册应用，先交付可运行的 MVP 版本。

## 技术范围
- 后端：`Spring Boot 3`、`MyBatis`、`SQLite`
- 管理端：`Sakai Vue`（布局风格参考 <https://sakai.primevue.org/>）
- 用户端：`Vue 3` + `vue-virtual-waterfall` + `swiper`

## 开发任务清单

### 任务1：项目基础初始化
- 创建工程结构：`backend`、`admin`、`client`
- 建立统一规范：环境变量、目录约定、基础脚本
- 补充最小启动文档（本地运行方式）

### 任务2：后端基础能力搭建
- 初始化 `Spring Boot 3` 项目
- 集成 `MyBatis` 与 `SQLite`，完成连接配置
- 建立统一返回结构、全局异常处理、基础日志配置
- 提供健康检查接口

### 任务3：核心数据模型与表结构设计
- 设计核心实体（建议）：用户、相册、图片
- 编写 `SQLite` 初始化脚本（建表与索引）
- 建立对应实体类、Mapper、基础 CRUD
- 准备测试种子数据（seed）

### 任务4：图片内容 API 开发
- 图片列表接口（分页 + 排序）
- 图片详情接口（用于轮播与详情展示）
- 管理端所需接口（新增、编辑、上下架、删除）
- 基础参数校验与错误提示

### 任务5：后台管理端开发（Sakai Vue）
- 初始化管理端项目并对齐 Sakai 风格
- 完成图片管理页面：列表、筛选、编辑、状态切换、删除
- 对接后端 API，补充加载态与操作反馈

### 任务6：用户侧前端开发
- 首页瀑布流：基于 `vue-virtual-waterfall` 展示图片
- 图片浏览：基于 `swiper` 实现轮播查看
- 完成交互状态：加载中、空数据、错误重试
- 实现基础分页/无限滚动策略

### 任务7：联调与质量验证
- 后端 + 管理端 + 用户端全链路联调
- 校验分页、滚动性能、轮播体验
- 修复主要功能缺陷与体验问题

### 任务8：交付准备
- 完善 `README`（安装、运行、配置、目录说明）
- 输出 MVP 版本说明
- 列出下一阶段迭代建议（可选）

## 建议优先级
- P0：任务1、任务2、任务3、任务4
- P1：任务5、任务6
- P2：任务7、任务8
